# Short-form configuration seed

This directory is a clean starting point for a new project. It contains configuration only: no generated audio, images, model logs, API keys, or finished video.

Copy it into `projects/<project-name>/`, edit `input/topic.json`, and then run the coordinator from the repository root. The default model names are examples and can be changed in `input/pipeline.json` or on individual command lines.

The included `transcript.example.txt` is only for testing the shot-planner dry run. Rename or replace it with the finalized transcript when that stage is ready.
